# testing-arkStudio

## Ссылка на деплой проекта

```sh
https://testing-ark.vercel.app/
```

## Установка зависимостей

```sh
npm install
```

### Запуск проекта в дев режиме
```sh
npm run dev
```

### Запуск сборки проекта

```sh
npm run build
```

### Просмотр сброки проекта

```sh
npm run preview
```
